# データ品質レポート — 都道府県 行動・消費マスター（無料サンプル版）

発行：Japan Open Data Lab
対象データ：都道府県 行動・消費マスター 無料サンプル（47都道府県 × 18列）
版：v1（2026-11-28 公開サンプル用）
検証者：データの制作者とは独立した立場で受入検証を実施（2026-11-10〜11）

このレポートは、本サンプルに収録したデータに対して「どんな検証をし、何が分かり、何がまだ分からないか」を公開するものです。品質を主張するのではなく、検証の内容と限界をそのまま示すことを目的としています。

## 1. 対象データと粒度の開示

- 47都道府県 × 19列（識別3列＋行動・消費指標16列）のマスターから、ライセンス判定が完了した18列を抜粋したものが本サンプルです（除外した1列については §4）。
- 指標には2つの粒度が混在します。都道府県全体の値（社会生活基本調査の時間系、持ち家率など）と、家計調査に基づく**県庁所在市の値で都道府県を近似**した指標（食・お金系）です。どの列がどちらの粒度かは、同梱の定義書に列ごとに明記しています。近似であることは隠さず、用途判断の材料として開示します。

## 2. 実施した検証

### 2.1 定義書との全列突合
全19列について、定義・単位・出典・対象年・粒度・計算式が定義書に記載され、マスターの実データと過不足がないことを確認しました。家計調査系の指標は品目コードレベルの計算式まで定義書に含まれています。

### 2.2 欠損（null）と 0 の分離
「データがない」ことと「値が 0 である」ことを取り違えていないかを確認しました。本マスターは47行×19列で欠損ゼロです。同じ検証プロセスを市区町村マスター（1,741自治体 × 228列）にも適用しており、そちらでは実例として、神奈川県清川村の PLATEAU 建物数が「0（＝建物なし）」ではなく「null（＝未整備でデータなし）」として正しく分離されていること、カバレッジフラグと数値列の矛盾が 0 件であることを確認しています。

### 2.3 公式公表値とのスポット突合（6指標・全件一致）
複数県 × 6指標で、発行元の公表値と突き合わせました。結果は全件一致です。

| 指標 | 突合した値の例 | 照合先 |
|---|---|---|
| 世帯当たり自家用乗用車普及台数 ※ | 福井 1.654台／東京 0.401台（他16県も一致、保有台数÷世帯数の再計算でも一致） | 自動車検査登録情報協会 公表値 |
| 持ち家率 | 秋田 77.1%／沖縄 42.6% | 住宅・土地統計調査 2023 |
| 睡眠時間 | 東京 468分 | 社会生活基本調査 2021 |
| 麺類支出 | 山形 26,372円/年（7品目の合計と完全一致） | 家計調査（SSDSE 公表値） |
| 外食割合 | 山形 16.84%／札幌 15.99%（定義式で再計算して一致） | 家計調査（SSDSE 公表値） |
| 貯蓄年収比 | 奈良 4.574倍／神戸 3.66倍（参考9市も一致） | 家計調査・貯蓄負債編 2024 |

※ 普及台数の列はライセンス上の理由で本サンプルには収録していません（§4）。検証自体はマスター全体に対して実施したものです。

正直な留保：麺類支出と外食割合の照合先は、本データの出典である SSDSE の公表データです。したがって検証できたのは「転記と計算式の適用の正確さ」までで、家計調査の原票からの独立再集計ではありません。他の4指標は発行元の独立した公表値で裏付けています。

### 2.4 分布の妥当性
各指標の最大・最小が既知の地域傾向と整合することを確認しました（例：自動車普及は福井が最大・東京が最小、麺類支出は山形が最大、持ち家率は秋田が最大・沖縄が最小）。

### 2.5 （参考）同じプロセスでの市区町村マスター検証
同じ受入検証プロセスでは、市区町村マスターについて国勢調査（2020年）の公表値と人口を突合し、千代田区 66,680人／世田谷区 943,664人／横浜市 3,777,491人などが全件一致、男女計＝総人口が全1,741行で一致、高齢化率の再計算一致、自治体コードの重複ゼロを確認しています。

## 3. 検証の限界（未検証の範囲）

- スポット突合は全数検査ではありません。全指標×全県の公表値突合は実施しておらず、上記の範囲が検証済みの射程です。
- 年次によって欠損の出方が異なる列があります（市区町村マスターの地価時系列など）。年次別の欠損は定義書と辞書側で確認できる形にしています。
- 独自算出インデックス類は検証対象外であり、公開・配布物には一切使用していません。

## 4. ライセンス監査と、収録しなかった1列について

配布に先立ち、全列の出典ごとに利用条件を監査しました。本サンプルに収録した18列は、政府標準利用規約／公共データ利用規約（PDL1.0）の対象となる政府統計、および出典明記で商用利用が認められる SSDSE 経由の列のみです。

1列だけ、意図的に収録しませんでした：

- **世帯当たり自家用乗用車普及台数**（出典：一般財団法人 自動車検査登録情報協会）。政府機関ではないため政府標準利用規約の対象外であり、同協会の公式な著作権方針では転載・複写に事前の承諾が必要とされています。「商用可」と判定できない以上、判定が終わるまで配布物には入れない、というのが本ラボの線引きです。診断サイト上での集計表示（出典明記）とは扱いを分けています。

監査の全体像（市区町村マスター228列の判定内訳を含む）は、監査メモとして別途管理しています。要確認の列は、判定が終わるまで無料サンプル・販売データのどちらにも入れません。

## 5. まとめ

- 定義の完全性、欠損と 0 の分離、公式値とのスポット突合（6指標・全件一致）、分布の妥当性、ライセンス監査までを実施した範囲で、本サンプルは「検証済み」と言える水準にあります。
- 同時に、検証は全数ではなく、照合の深さには指標ごとの差があります。その差も含めてこのレポートに開示しました。データの採用判断は、この開示ごとご判断ください。
